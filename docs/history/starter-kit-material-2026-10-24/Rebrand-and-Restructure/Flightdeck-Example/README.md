# Flightdeck

A local React + TypeScript PWA prototype for flight summaries, destination weather and arrival inspiration. Flight details currently use clearly labelled samples; live weather was previously tested. Live flight-provider access remains blocked. Current backend is Node/Express, not PHP.

## Run locally

```sh
pnpm install
pnpm dev
```

Vite runs at http://127.0.0.1:5173 and proxies API to loopback 3001. Use one API instance at a time. `pnpm test` runs four domain tests. `pnpm build` checks types and builds frontend/PWA assets. `pnpm start` serves built assets and API locally through tsx; this is not a verified cPanel deployment configuration. Existing project pins live in mise.toml/package.json.

## Honest limits
No live flight key, account system, database, Git repo/remote, selected public domain or deployment workflow is configured. Boarding and aircraft position are unavailable. Destination guides cover three demo cities. PWA install/update/accessibility still need release testing. PHP/cPanel is the preferred future target, not an implemented migration.

Never commit .env or put private keys in VITE_* values. The existing .env.example is preserved and lists current server configuration only. No real .env is generated by the documentation kit. See archived prior README in docs/history for historical setup details, not current release authority.
