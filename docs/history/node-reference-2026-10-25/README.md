# Archived: Node/Express reference server (25 Oct 2026)

The original Express prototype (`server/`) and the Node-vs-PHP parity script, archived with the owner's approval on 25 October 2026 (ADR-018). Production has run only the PHP API since 24 October 2026 (ADR-007). This code has no sign-in, owner console, enquiries, CMS or public site, and the release workflow did not test it.

To run it again, restore the folder to the project root and re-add `express`, `dotenv` and `@types/express` (see git history before this commit). It is kept as evidence, not as current instructions.
