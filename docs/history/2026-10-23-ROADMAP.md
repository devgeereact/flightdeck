# Flightdeck build roadmap

## Working prototype
- React/TypeScript flight dashboard and responsive layout
- Flight search and sample journeys
- Live current weather, local clocks and destination guides
- Saved flights and optional foreground polling
- Server-side FlightAware adapter, validation and tests

## Next build milestones
1. Connect an authorised live flight feed and validate provider responses with real flights.
2. Add aircraft-position and boarding sources where available; never infer operational values.
3. Add worldwide destination enrichment with official tourism references and nearby-place distances.
4. Expand integration and browser tests, including timezones, cancellations, diversions and stale responses.
5. Add install/update UX, PNG PWA icons, offline QA and accessibility checks.
6. Prepare deployment: managed secrets, shared cache/rate limiting, spending limits, HTTPS and monitoring.

Live airline data is not yet connected. Do not present samples as live updates. Never commit API keys.
